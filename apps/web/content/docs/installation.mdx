---
title: Installation
description: Set Prism up in an existing project and add your first component.
---

## Initialize

```bash
npx @defied/prism-cli init
```

For a Vue project:

```bash
npx @defied/prism-cli init --framework vue
```

## Add a component

```bash
npx @defied/prism-cli add dialog
```

Registry dependencies (a dialog's trigger is a `Button`) are installed first.

## Switch styling later

```bash
npx @defied/prism-cli sync --style css-modules
```
