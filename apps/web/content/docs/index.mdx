---
title: Introduction
description: Accessible components for React or Vue, styled with Tailwind, CSS Modules or plain CSS, written into your repo as code you own.
---

Prism is a registry, not a dependency. `prism add` writes a component's source into your project, generated for the framework and styling target you picked. Edit it freely; regenerate when you want the latest.

Every component ships for **React and Vue**, and for **Tailwind, CSS Modules and plain CSS**. Each one is checked in CI against its contract and axe, in every CSS target.
