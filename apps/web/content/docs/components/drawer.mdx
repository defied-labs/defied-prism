## Installation

```bash
npx @defied/prism-cli add drawer
```

`button` is installed with it: the trigger and close parts render a `Button`.

## Usage

`Drawer` holds the open state, `DrawerTrigger` toggles it, and `DrawerContent` is the panel. Give every drawer a `DrawerTitle`; it names the panel for screen readers. `DrawerClose` closes it, and `DrawerFooter` lays out the actions. Pass `asChild` to the trigger or close part to render your own element instead of a `Button`.

`closeOnEscape` and `closeOnOutsideClick` (both on by default) control dismissal, and `initialFocus` picks the element focused on open instead of the first focusable one.

## Side and controlled state

`side` picks the edge (`right` by default, or `left`, `top`, `bottom`) and `size` its width or height (`sm`, `md`, `lg`, `full`). To drive the open state yourself, in React pass `open` and `onOpenChange`; in Vue bind `v-model:open`. Here the drawer closes when a link is followed.
