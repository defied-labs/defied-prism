## Installation

```bash
npx @defied-prism/cli add inline
```

## Usage

Wrap the items in `Inline`. Defaults are `gap="sm"`, `align="center"`, `justify="start"` and `wrap="wrap"`; set `wrap="nowrap"` to keep everything on one line. Use `as` to render a list (`ul`, `ol`) or a landmark (`nav`, `header`, `footer`, `section`) instead of a `div`.

## Spreading items

`justify="between"` pushes the first and last children to the edges, which suits toolbars and footers. Inlines nest: the inner one groups the buttons.
