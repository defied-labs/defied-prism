## Installation

```bash
npx @defied-labs/prism-cli add surface
```

## Usage

`variant` picks the look: `flat`, `raised` (shadow), `outlined` (border), or `sunken` (recessed background). `padding` sets inner spacing from `none` to `lg`. `as` renders a `section`, `article` or `aside` instead of a `div` when the panel is a landmark or standalone piece of content.
