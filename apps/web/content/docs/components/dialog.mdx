## Installation

```bash
npx @defied/prism-cli add dialog
```

`button` is installed with it: the trigger and close parts render a `Button`.

## Usage

The parts nest: `Dialog` holds the state, `DialogTrigger` opens it, and `DialogContent` is the modal itself. Give every dialog a `DialogTitle`; it names the dialog for screen readers.

## Controlled

Drive the open state yourself. In React pass `open` and `onOpenChange`; in Vue bind `v-model:open`. Use `role="alertdialog"` for destructive confirmations: outside clicks no longer close it, so the choice has to be explicit.
