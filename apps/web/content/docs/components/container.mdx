## Installation

```bash
npx @defied-labs/prism-cli add container
```

## Usage

Wrap page content in `Container` to cap its width and center it. `size` sets the maximum width: `sm` 40rem, `md` 48rem, `lg` 64rem (the default), `xl` 80rem, or `full` for no limit. It renders a `div` unless you pick another element with `as` (`section`, `main`, `header` or `footer`).
