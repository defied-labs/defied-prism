## Installation

```bash
npx @defied/prism-cli add progress
```

## Usage

Pass `value` (clamped to `min`–`max`, 0–100 by default) and name the bar with `aria-label` or `aria-labelledby`. Screen readers announce the percentage unless you give `valueText`, either a string or a function of the value and percentage. When you can't measure progress, set `indeterminate` (or pass `value={null}`): the bar animates and `aria-valuenow` is left out.

## Status and size

`status` colors the bar (`neutral`, `info`, `success`, `warning`, `danger`; default `info`) and `size` sets its height (`sm`, `md`, `lg`).
