## Installation

```bash
npx @defied-labs/prism-cli add spinner
```

## Usage

`Spinner` renders a `role="status"` element with a visually hidden `label` (default "Loading"), so it is announced when it appears. Pick `size` from `xs` to `lg`; the ring takes `currentColor`, so set `color` on it or a parent to tint it. Give the label something specific, like "Loading invoices", when the context isn't obvious.
