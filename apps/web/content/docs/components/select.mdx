## Installation

```bash
npx @defied/prism-cli add select
```

## Usage

`Select` holds the value, `SelectTrigger` is the combobox button (it shows the selected item's text, or `placeholder`), and `SelectContent` is the listbox of `SelectItem`s. Focus stays on the trigger while the list is open: arrow keys move the highlight, typing jumps to a matching item, and Enter or Tab selects. Put it in a `Field` with a `FieldLabel` to name it. Read and set the value with `value` and `onValueChange` in React, or `v-model` in Vue.

## Groups and forms

Wrap related items in `SelectGroup` with a `SelectLabel` heading, and divide groups with `SelectSeparator`. Give the `Select` a `name` to submit its value with a form through a hidden input.
