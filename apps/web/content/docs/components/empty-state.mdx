## Installation

```bash
npx @defied-labs/prism-cli add empty-state
```

## Usage

Compose the parts in order: `EmptyStateIcon` (decorative, hidden from screen readers), `EmptyStateTitle`, `EmptyStateDescription` and `EmptyStateActions`. All are optional except the title. The title renders as an `h3` by default; set `headingLevel` on `EmptyState` to fit your page outline.

## Small

Use `size="sm"` inside cards, panels and search results, where a full-size empty state would dominate.
