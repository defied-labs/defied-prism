# @defied-labs/prism-core

Framework-agnostic building blocks for [Defied Prism](https://github.com/defied-labs/defied-prism) components: state machines, DOM primitives (focus trapping, dismissal, scroll locking, roving focus, exit animations) and the styling helpers generated components call.

You normally don't use this package directly. Components added with [`@defied-labs/prism-cli`](https://www.npmjs.com/package/@defied-labs/prism-cli) import it, so install it alongside them:

```sh
npm install @defied-labs/prism-core
```
