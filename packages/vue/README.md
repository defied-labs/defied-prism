# @defied/prism-vue

Vue runtime for [Defied Prism](https://github.com/defied-labs/defied-prism): the composables and primitives (controllable state, state machines, presence for exit animations) that components generated by [`@defied/prism-cli`](https://www.npmjs.com/package/@defied/prism-cli) import.

```sh
npm install @defied/prism-vue @defied/prism-core @defied/prism-tokens
```

Requires Vue 3.4 or later.
