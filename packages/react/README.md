# @defied/prism-react

React runtime for [Defied Prism](https://github.com/defied-labs/defied-prism): the hooks and primitives (controllable state, state machines, presence for exit animations, `Slot`) that components generated by [`@defied/prism-cli`](https://www.npmjs.com/package/@defied/prism-cli) import.

```sh
npm install @defied/prism-react @defied/prism-core @defied/prism-tokens
```

Requires React 18 or later.
