# @defied-labs/prism-react

React runtime for [Defied Prism](https://github.com/defied-labs/defied-prism): the hooks and primitives (controllable state, state machines, presence for exit animations, `Slot`) that components generated by [`@defied-labs/prism-cli`](https://www.npmjs.com/package/@defied-labs/prism-cli) import.

```sh
npm install @defied-labs/prism-react @defied-labs/prism-core @defied-labs/prism-tokens
```

Requires React 18 or later.
